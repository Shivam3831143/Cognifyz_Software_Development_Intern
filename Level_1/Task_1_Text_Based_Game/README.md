
# Task 1: Number Guessing Game

## Internship
Cognifyz Technologies — Software Development Internship

## Description
A text-based Python game in which the computer randomly selects a number between 1 and 100, and the player tries to guess it.

## Features
- Random number generation
- Higher and lower hints
- Repeated guessing until the correct answer
- Attempt counter
- Invalid input handling
- Play-again option

## Technologies Used
- Python 3
- random module

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

   python main.py

## Concepts Learned
- Variables and data types
- Conditional statements
- While loops
- Functions
- Exception handling
- Random number generation

## Testing
- Tested guesses that were too high or too low.
- Tested invalid text input.
- Tested numbers outside the allowed range.
- Tested winning and replay functionality.

## Learning Outcome
Learned to develop an interactive console application using Python control flow, functions, loops, and input validation.
