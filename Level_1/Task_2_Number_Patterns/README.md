# Task 2: Number Patterns

## Internship
Cognifyz Technologies — Software Development Internship

## Description
A Python console program that generates different number patterns based on the number of rows entered by the user.

## Features
- Increasing number pattern
- Repeated row number pattern
- Decreasing number pattern
- User-defined number of rows
- Input validation and error handling

## Technologies Used
- Python 3

## Concepts Learned
- `for` loops
- Nested loops
- Functions
- Conditional statements
- User input
- Exception handling

## How to Run
From the project root, run:

`python Level_1/Task_2_Number_Patterns/main.py`

## Testing
Tested with valid row counts, out-of-range values, and invalid text input.

## Learning Outcome
Learned how nested loops generate patterns and how functions organize a Python program.
