# Task 3: Console-Based Task Manager

## Internship
Cognifyz Technologies — Software Development Internship

## Description
A menu-driven Python console application that allows users to manage a list of tasks through CRUD operations.

## Features
- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Handle invalid menu choices and task numbers
- Prevent empty task entries

## Technologies Used
- Python 3

## CRUD Operations
- **Create:** Add a task to the list.
- **Read:** Display the saved tasks.
- **Update:** Modify an existing task.
- **Delete:** Remove a selected task.

## How to Run
From the project root, execute:

`python Level_2/Task_3_CRUD_Task_Manager/main.py`

## Concepts Learned
- Lists and list operations
- Functions
- Loops and conditional statements
- Exception handling
- Menu-driven program design

## Limitation
Tasks are stored in memory and are not retained after the program exits.

## Learning Outcome
Learned to build a modular console application implementing all four CRUD operations.
