# Task 4: Temperature Converter

## Internship
Cognifyz Technologies — Software Development Internship

## Description
A Python console application that converts temperatures between Celsius and Fahrenheit.

## Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Numeric input validation
- Formatted temperature output

## Technologies Used
- Python 3

## Formulas
- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9

## How to Run
From the project root, execute:

`python Level_2/Task_4_Temperature_Converter/main.py`

- Arithmetic operations
- Conditional statements
- User input

- Formatted output
